Zen Recorder

A local meeting recorder for Firefox-based browsers. It records your Google Meet, Zoom and Microsoft Teams calls, and each meeting becomes files on your own disk, made to be the best input for an AI assistant that analyses a meeting.

Nothing leaves your machine: no servers, no accounts, no uploads, no telemetry.

Add to Firefox

Install

  1. Open Zen Recorder on Firefox Add-ons and click Add to Firefox.
  2. Accept the install prompt. It lists the sites the recorder works on (Google Meet, Zoom, Microsoft Teams); leave them all allowed.

Each version is also on GitHub: download zen-recorder-<version>.xpi from the latest release, the same file signed by Mozilla, and drag it onto a browser window, or open about:addons, click the gear icon and choose Install Add-on From File….

BrowserWhat to do
Firefox 140 or later (release, ESR, Beta, Developer Edition, Nightly) The steps above.
Zen The same steps. You do not need to change any pref, because the file is signed.
LibreWolf, Floorp, Waterfox and other Firefox-based browsers The same steps.
Chrome, Edge and other Chromium-based browsers; Firefox for Android Not supported.

Updates

Updates are automatic, from addons.mozilla.org, however you installed it. After an update the popup may show Grant access for a service that is new in that version: Firefox asks for each site's permission separately.

Coming from version 0.3.0 or older? The add-on id changed, so follow the one-time steps for the new add-on id in the changelog first.

Privacy

Recordings are saved as files in your Downloads folder, and nothing is sent anywhere. The privacy page says more.

About

Zen Recorder is an independent project. It is not affiliated with, endorsed by or sponsored by Zen Browser or its team. The maintainer uses Zen Browser, which is why the recorder targets Firefox-based browsers.
